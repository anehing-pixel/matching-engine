## 文档维护规则

1. **文档与代码同源**：功能上线时同步更新对应章节，不允许"代码改了文档没改"。
2. **规格文档先于实现**：`02` 里每个功能开发前应先确认规格，开发中如有偏离需回写。
3. **验收标准必须可执行**：写"支持资金费率"不算标准，写"给定费率 0.01%、
   多空持仓相等时，结算后多空双方保证金变动之和为 0"才算。
4. **术语统一**：见 `01` 末尾的术语表，新增术语先进表再使用。
